# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my projects, technical skills, and experience as an IT Graduate and Software Developer. The portfolio features a clean user interface, responsive design, interactive animations, downloadable CV support, and a working contact form.

---

## 🚀 Live Demo

🔗 [View Portfolio]([https://resonant-faun-b0e996.netlify.app])

---

# ✨ Features

- Responsive design for desktop, tablet, Android, and iOS devices
- Modern glassmorphism-inspired UI
- Interactive project showcase section
- Downloadable CV button
- Contact form integration using Formspree
- Dark/Light mode toggle
- Smooth animations and hover effects
- Social media integration
- Skills section with technology icons
- Mobile-friendly layout
